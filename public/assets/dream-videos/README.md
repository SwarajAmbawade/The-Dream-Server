# Default dream video assets

Put local video files in this folder. The viewer uses these videos only for built-in starter dreams; user-created dreams use the interactive story experience instead.

Use these exact filenames (MP4 recommended):

- `flying-over-glass-city.mp4`
- `endless-staircase.mp4`
- `tea-in-lavender-garden.mp4`
- `underwater-library.mp4`
- `chased-by-a-clock.mp4`
- `the-door-nobody-opened.mp4`
- `train-in-a-memory.mp4`
- `the-static-sump.mp4`
- `library-of-fallen-leaves.mp4`
- `door-at-the-end-of-the-sea.mp4`
- `city-beneath-the-ocean.mp4`

A missing file will not break the app; that dream falls back to the interactive viewer. Filenames are mapped in `../dream-videos.json`.

Use only videos you created, have permission to reuse, or that are licensed for your intended use. A YouTube link by itself does not grant permission to download or redistribute a creator's video.
