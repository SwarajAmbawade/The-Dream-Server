# Curated dream artwork

Place your own AI-generated or otherwise properly licensed images in this folder.
Recommended format: WebP or JPEG, landscape 3:2 or 16:9, ideally 1200px wide and under 1 MB.

The matching map is `../dream-images.json`. Keys are dream titles in lowercase; values must be filenames in this folder. Curated files are served locally and never trigger Pixabay calls.

Suggested prompts should be based on the scene itself (e.g. an abandoned ancient city submerged beneath a deep blue ocean, distant towers, shafts of moonlight and a large golden moon; cinematic surreal dream art; no text, no watermark).

Only use images you generated yourself or have permission to use. If using generated images, keep a copy of the prompt and note the tool/model used for project documentation.
